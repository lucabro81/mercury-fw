These are the packages Mercury's own repository publishes. `mfw create` offers all of them, and each page says what
the package does, how to add it to an app that already exists, and the settings it reads.

- A **channel** is where people talk to the agent ([Channels](../concepts/channels/)).
- An **auth provider** tells the HTTP channel who is calling, and a **directory** who that person is and their
  roles ([People and roles](../concepts/people/)).
- A **tool plugin** gives the agent things to do ([Plugins and skills](../concepts/plugins/)).

A plugin can also be a file in your app: [Your first plugin](../getting-started/local-plugin/) shows how.
