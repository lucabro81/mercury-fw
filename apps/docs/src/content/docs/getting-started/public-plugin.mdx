A plugin written inside your app serves that app. When a plugin is useful to others (it wraps a service many
teams use, say), it can become one of Mercury's own packages: it lives in the Mercury repository, gets published
on npm as `@mercury-fw/<name>`, and shows up among the choices of `mfw create`.

This page will explain how to propose one, once the way plugins are written settles. Until then, open an issue on
[the repository](https://github.com/lucabro81/mercury-fw/issues) describing the service and what the agent should
do with it.
