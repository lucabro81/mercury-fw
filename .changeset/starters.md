- `mfw create --starter <id>`: an agent set up for a task, `knowledge-base` (Confluence), `jira-assistant` (Jira) or `web-researcher` (web search): its plugins, its role, an e2e test in `e2e/<id>.e2e.ts`, a section of the README
- `mfw create` asks what the agent is for, a starter or nothing, and pre-fills from it
