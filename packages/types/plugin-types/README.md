# @mercury-fw/plugin-types

The contract a [Mercury](https://github.com/lucabro81/mercury-fw) tool plugin implements: `Plugin`, `PLUGIN_API_VERSION` and the types around them (what `build()` receives and returns, skills, lists handed to the user, the texts a person sees: `Messages`, `Translate`). Plugin authors get it through [`@mercury-fw/kit`](https://www.npmjs.com/package/@mercury-fw/kit); it's a package of its own so the core and the plugins share one definition.
