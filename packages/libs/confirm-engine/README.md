# @mercury-fw/confirm-engine

The confirmation mechanism of [Mercury](https://github.com/lucabro81/mercury-fw): stages an action behind a one-time token and runs it when the token comes back. The core uses it and injects it into the channels; you don't depend on it directly.

On Mercury's documentation site: [Confirmations](https://lucabro81.github.io/mercury-fw/concepts/confirmations/).
